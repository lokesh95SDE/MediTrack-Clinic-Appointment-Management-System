JDK:(JRE+JVM) Java development kit where we can write our Code to develop a application using Development tool that help us to compiling, document and debugging Here Javac converts the java code into Byte code.

JRE:(contains JVM) Java Runtime Environment helps to run the program and contains Core Java Libraries

JVM: Which make java as platform independent by executing byte code in any platform such as Linus or Windows os.

Write Once, Run Anywhere means Java code can be written one time and executed any time in any OS without modification if that system as JVM Byte Code is the intermediate and platform independent code generated by Java compiler. Byte code is not human-readable. Executing in byte code help improve performance as well where JIT converts Byte code to Machine Code.


Class Loader : Loads the .class files into memory
Heap Memory  : Here all objects stored (eg: Doctor or Patient Objects stored here )
Stack Memory : Local variable and Method call are stored
Method Area  : Stores class metadata
PC registers : Current Instruction

When comparing Interpreter vs JIT Compiler
Execution in interpreter is line by line here in JIT compiler it complies entire blocks to native Code(machine Language)
Start up time in interpreter is FAST and in JIT Compiler it is slow due to compilation over head
Runtime Speed in interpreter is Slow and in JIT compiler it is Faster for repetitive
Efficiency is Low in interpreter and High in JIT compiler for hot code in
